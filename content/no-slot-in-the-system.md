下午的便利商店，一個孩子把攢了整年的壓歲錢推過櫃臺，想存起來。店員說他沒有帳戶，那筆錢只好塞回紅包袋，回到書桌抽屜。

在台灣的金融體系裡，十八歲以下的人幾乎是隱形的。研究所那幾年我做了三個東西，事後回頭看，它們服務的都是同一種人：系統裡沒有他那一格的人。

## 三個題目共用的那道縫

晚上九點的熱炒既不算一餐，也還不是垃圾，所以沒有人負責它。一個搜尋不到的水電師傅，在需要他的人眼中等於不存在。一個未成年的孩子沒辦法開戶，金融系統就沒有地方記錄他。

三件事看起來差很遠，但每一次動手，最花力氣的部分都不在程式。真正的工作是先替那群人發明一個分類，再造一個機制讓這個分類被看見。

## 讓那三份熱炒有一個名字：粒粒珍食

那三份熱炒的賣相，跟三小時前剛上桌時幾乎一樣，只是過了尖峰時段，它就從「餐食」變成「剩食」。還沒煮過、品質沒問題、只是賣相不夠漂亮的農產品，則叫「格外品」。兩格的共同點一樣：沒有壞掉，只是找不到人。

粒粒珍食做的事，是把「搶」換成「約」。餐廳打烊前上架剩食數量與取餐時段，消費者用定位看附近有什麼、線上預約，拿一組 Qrcode 到店取餐。消費者不必再盯著店員貼黃標的手，餐廳也能提前知道有幾個人會來。

讓這套預約制站得住的，是三條規則：價格必須至少低於原價 20%；完售或打烊可以即時下架；多次預約卻不取餐的人會被暫時限制。三條規則堵的都是恐懼：店家怕公開了卻沒人來拿，消費者怕白跑一趟。沒有一條是工程題目。

一家合作店家一個月少丟 12 公斤食物，多賺 11,400 元營收，少排 31.2 公斤碳。平台把這些整理成月報與季報，讓惜食變成可以放進 ESG 報告的一行數字。

然後我們沒有繼續做，原因跟系統設計無關。

剩食經濟在歐洲跑得動，是因為那裡的食物夠貴：打折後的價差大到值得消費者為它多走一段路、多等一個時段。台灣的結構不一樣。一份熱炒本來就便宜，打八折省下來的那幾十塊，換不到「特地繞過去一趟」的動機。供給端的誘因我們用規則補起來了，需求端的節省卻不夠痛，整條鏈就轉不動。

這件事是把平台做完、真的跑過店家之後才確定的。它不寫在任何一份簡報裡。

## 讓師傅被搜尋得到：Shooly

深夜的租屋處，水管忽然滲水，你抓著手機滑過一頁又一頁評論，還是不知道該打給誰。另一頭的師傅其實就在幾條街外，只是傳統水電產業的曝光管道有限，他沒辦法累積一份被搜尋得到的信譽。

Shooly 把入口放在 LINE，因為不必再下載一個 App。選好「項目 × 地區」就能看到附近技師的資歷、證照與評價，再串 Google Maps API 看路線與抵達時間。

整套系統最關鍵的一塊，是不需要加好友的對話機制。伺服器端先把雙方的 User ID 配對起來，再用 LINE Push API 打通雙向對話，使用者可以直接傳照片或影片，讓技師遠端判斷跟報價。會這樣設計，是因為真正的障礙不在介面：陌生人不會在 LINE 上互加好友。

有兩個地方我們沒有解決，只是繞過去。LINE 不讓 Chatbot 在背景取得使用者位置，我們的做法是透過 LIFF，在使用者每次開啟介面時記錄一次位置，原生 App 留在規劃裡。另一個是錢：一對一對話靠 LINE Push API，推播不便宜，所以對話流程被刻意壓到最小。這兩件事寫在簡報上都很順，實際上都是妥協。

後來累積了 15 個村里與鄉鎮辦公室合作、30 位技師實際接洽、超過 10,000 人次的推播觸及，也拿下 2020 LINE Chatbot 設計大賽全國冠軍。

## 十八歲以下的人，在金融系統裡沒有欄位

回到櫃臺前那個孩子。現行制度下，兒童與青少年無法獨立開戶，每一筆金流都得依附在大人身上。親子之間給錢、還錢、發獎勵，全靠口頭跟記憶，事後誰也說不清。

市面上幾乎所有金融產品都為成人設計。更麻煩的是，沒有人把「家庭」當成一個會一起做決定、也需要被一起記錄的單位。孩子懂錢，只是從來沒有一個安全的地方讓他練習。

## 主卡與附卡，是我們借來的那個分類

信用卡早就處理過一個很像的情境：一個人在另一個人的額度裡花錢，額度的主人看得到每一筆。PP-Bank 把這個關係從消費延伸出去，做成一套階層式帳戶模型。

家長帳戶是資金的最終管理者，可以建立並授權多個子女帳戶，控制金流與消費權限。子女帳戶有自己的介面與行為紀錄，金流即時、透明地回到家長端。孩子拿到的不是一個帳戶，是一個由大人劃出來、而他可以在裡面真正操作的邊界。這一步之後，「未成年人不能開戶」就不再是死路，因為需要被記錄的主體從個人換成了家庭。

有了邊界，才輪到內容。家長指派一項生活任務，洗碗、背完單字、整理房間，孩子完成後系統即時發放金錢或點數，收支與儲蓄的變化就在畫面上長出來。儲蓄於是從大人嘴上的美德，變成孩子看著數字慢慢變多的體感。

底層全面採用 API-First，開放銀行帳務、即時交易查詢、投資商品介接都是可以獨立替換的模組，要加一項新產品，接一支 API 就好。

做完的那一刻，我沒把握評審會不會買單。這套東西的價值全押在一個判斷上：「家庭是一個帳務單位」這件事，有沒有人認同。最後 PP-Bank 在全國創新技術 API 實證競賽拿下第一名，從 300 多組隊伍裡出線，評審肯定的是 API 整合的深度、架構的延展性，以及一個明確的社會價值場景。

## 那個沒被縫進這條線的第一站

這條線不是一開始就有的。2019 年 5 月的第一站是一個線上智慧展覽館，讓人在網站上身歷其境地探索展覽，拿了中科智慧創新創業競賽第二名。四個題目裡只有它不在這條線上：它服務的人本來就有位置，缺的只是更好的體驗。比完賽就沒有再做了。

## 四個都停了

Shooly 和 PP-Bank 現在也沒有在跑。原因比粒粒珍食單純：團隊散了，沒有人接手維護，系統就停在得獎那天的樣子。

後來的創業歸故里全國決賽、FITI 全國 40 強、教育部 U-Start 補助，是別人在這條路上投下的信任票。但四個題目，沒有一個活下來。

得獎證明的是評審看懂了那個分類。它沒有證明那些人真的被接住。這兩件事之間的距離，是我隔了一段時間才看清楚的。

遇到一個沒人在處理的問題，先別急著問技術上怎麼做，先問它為什麼沒有欄位。很多時候答案只是沒有人替它命名。下次遇到一件「大家都說沒辦法」的事，先給它一個名字，再看看剩下多少是真的做不到。
